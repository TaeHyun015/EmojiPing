# Sephiria Emoji Ping

[한국어](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

캐릭터 머리 위 중앙에 이모지를 표시하는 세피리아 모드입니다. 게임 원본 이모지 5종과 사용자 제작 PNG 애니메이션을 지원합니다. 현재 공개 버전은 **1.0.2**입니다.

## 설치

[Releases](https://github.com/TaeHyun015/EmojiPing/releases)에서 **EmojiPing-1.0.2.zip**을 다운로드하세요. 게임을 종료하고 ZIP의 `AddOns/EmojiPing` 폴더를 게임 설치 폴더의 `AddOns`에 복사한 뒤 게임을 실행합니다. 업데이트 시 기존 `pack.json`과 `Images` 폴더를 보존하세요. 게임 기본 모드 로더를 사용하며 BepInEx는 필요하지 않습니다.

## 사용법

1. 기본 키 **백틱(숫자 1 왼쪽의 키)**을 길게 누릅니다. 개인 키를 바꿨다면 해당 키를 사용합니다.
2. 마우스를 원하는 이모지 칸 안으로 옮긴 뒤 키를 놓습니다.
3. 빈 공간에서 놓거나 **Esc**를 누르면 취소합니다.

5개 이모지는 정오각형으로 배치되고 선택한 칸은 밝은 테두리로 강조됩니다. 다른 개수도 자동 배치하며 마우스 휠 클릭의 기본 핑은 계속 사용할 수 있습니다.

- 키 변경: **설정 → 키보드 → 이모지 선택 (EP)**
- 이미지 새로고침: **설정 → 키보드 → 이모지 이미지 (EP) → 다시 읽기**, 또는 **Ctrl + 현재 이모지 키**
- 기본 표시 시간은 2.5초, 사용 간격은 0.75초입니다.

## 커스텀 이모지

`Images` 아래에 이모지별 폴더를 만들고 `1.png`, `2.png`, … `8.png`로 프레임을 저장합니다. 한 장이면 정지 이미지입니다. 번호는 연속이어야 하며 모든 프레임의 크기는 같아야 합니다.

| 항목 | 규격 |
|---|---|
| 권장 제작 크기 | 16×16 또는 24×24, 표시 크기와 동일하게 |
| 최대 원본 크기 | 프레임당 64×64 |
| 표시 크기 | 긴 변 8~24 논리 픽셀 |
| 형식 | 8비트 RGBA PNG, 투명 배경 권장 |
| 애니메이션 | 최대 8프레임, 1~12 FPS |
| 용량·종류 | 이모지당 최대 1 MiB, 팩당 최대 8종 |

픽셀 펜으로 제작하고 안티앨리어싱·블러를 피하세요. 새 폴더는 **`pack.json`의 `emojis`에도 등록해야 합니다.** 폴더 자동 추가는 지원하지 않습니다. 예를 들어 `Images/my-heart`의 24×24 프레임을 사용하려면 다음 항목을 추가합니다.

```json
{"id":"my-heart","name":"하트","folder":"my-heart","fps":8,"displayPixels":24}
```

저장 후 이미지 새로고침으로 적용하세요. ZIP의 `Templates`에는 투명 프레임과 엄지척 8프레임 제작 예제가 있습니다.

## 멀티플레이

Steam 로비에서 같은 최신 버전의 모드를 설치한 사용자끼리 각자의 커스텀 이모지를 직접 공유합니다. 모드 사용자에게는 멀티 목록의 닉네임 오른쪽에 **EP 표식**이 표시됩니다. 미설치 사용자는 표식과 모드 이모지를 볼 수 없습니다. 호스트의 설치 여부와 관계없이 공유하도록 구현했으며, 직접 통신을 사용할 수 없으면 로컬 표시를 유지합니다.

## 자동 업데이트

게임에서 모드를 불러올 때 이 저장소의 최신 정식 Release를 확인합니다. 새 버전이 있으면 안내 창이 표시되며, 동의하면 다운로드 후 게임을 종료하고 업데이트·재실행합니다. **현재 진행 상황을 저장한 뒤 이용하세요.** 커스텀 이미지, 팩 설정, 개인 키는 보존합니다.

업데이트용 `EmojiPing-update.zip`은 기존 설치의 자동 업데이트 전용입니다. 처음 설치할 때는 전체 ZIP을 사용하세요. 자동 확인을 끄려면 모드 폴더에 빈 `disable-updates.txt` 파일을 만드세요. 업데이트 실패 로그는 게임 폴더의 `__EmojiPing_Update.log`와 `Player.log`에서 확인할 수 있습니다.
