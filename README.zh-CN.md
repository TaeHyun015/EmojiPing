# Sephiria Emoji Ping

[한국어](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

这是一个为《Sephiria》添加角色头顶表情的模组。支持游戏原有的5种表情，以及玩家自制的PNG动画。当前公开版本为 **1.0.2**。

## 安装

从 [Releases](https://github.com/TaeHyun015/EmojiPing/releases) 下载 **EmojiPing-1.0.2.zip**。关闭游戏，将ZIP内的 `AddOns/EmojiPing` 文件夹复制到游戏的 `AddOns` 目录，再启动游戏。手动更新时请保留已有的 `pack.json` 和 `Images`。本模组使用游戏内置的模组加载器，无需BepInEx。

## 使用方法

1. 按住默认的 **反引号键（数字1左侧的按键）**，或你自行设置的表情按键。
2. 将鼠标移到想使用的表情格内，再松开按键。
3. 在空白处松开按键或按 **Esc** 即可取消。

5个表情格按正五边形排列，选中的格子会显示明亮边框。其他数量也会自动排列。游戏原有的鼠标滚轮点击标记仍可使用。

- 修改按键：**设置 → 键盘 → 表情选择（EP）**
- 重新载入图片：同一选项卡中的 **表情图片（EP）→ 重新读取**，或 **Ctrl + 当前表情按键**。设置项目名称可能显示为韩语。
- 默认显示时间为2.5秒，使用间隔为0.75秒。

## 自定义表情

在 `Images` 下为每种表情创建独立文件夹，按 `1.png`、`2.png`、… `8.png` 命名保存帧。只有一张时显示静态图片。编号必须连续，所有帧的尺寸必须相同。

| 项目 | 规格 |
|---|---|
| 推荐画布 | 16×16或24×24，与显示尺寸一致 |
| 原图最大尺寸 | 每帧64×64 |
| 显示尺寸 | 长边8～24逻辑像素 |
| 格式 | 8位RGBA PNG，建议透明背景 |
| 动画 | 最多8帧，1～12 FPS |
| 容量与数量 | 每种表情最多1 MiB，每个表情包最多8种 |

请使用像素铅笔绘制，避免抗锯齿和模糊。新增文件夹后，**还必须在 `pack.json` 的 `emojis` 数组中注册**；目前不支持自动发现文件夹。例如，在 `Images/my-heart` 中放入24×24的帧时，可添加以下条目：

```json
{"id":"my-heart","name":"爱心","folder":"my-heart","fps":8,"displayPixels":24}
```

保存后重新载入图片即可生效。ZIP中的 `Templates` 包含透明帧和8帧点赞制作示例。

## 多人游戏

在Steam大厅中，使用同一最新模组版本的玩家可直接共享各自的自定义表情。模组用户可以在多人列表的昵称右侧看到 **EP标识**。未安装模组的玩家看不到此标识和模组表情。共享功能不依赖房主是否安装模组；无法直接通信时仍可在自己的画面中使用表情。

## 自动更新

游戏加载模组时会检查本仓库最新的正式Release。发现新版本后显示游戏内提示，经你同意后下载文件，然后关闭游戏、安装更新并重新启动。**请先保存当前游戏进度。** 自定义图片、表情包设置和个人按键设置会保留。

`EmojiPing-update.zip` 仅用于已有安装的自动更新。首次安装请使用完整ZIP。如需关闭更新检查，请在模组目录内创建空的 `disable-updates.txt`。更新失败时可查看游戏目录中的 `__EmojiPing_Update.log` 和 `Player.log`。
