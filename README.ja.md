# Sephiria Emoji Ping

[한국어](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

キャラクターの頭上中央に絵文字を表示する『Sephiria』用MODです。ゲーム本来の絵文字5種類と、ユーザー制作のPNGアニメーションに対応しています。現在の公開バージョンは **1.0.1** です。

## インストール

[Releases](https://github.com/TaeHyun015/EmojiPing/releases)から **EmojiPing-1.0.1.zip** をダウンロードします。ゲームを終了し、ZIP内の `AddOns/EmojiPing` フォルダーをゲームの `AddOns` フォルダーにコピーしてから起動してください。手動更新時は既存の `pack.json` と `Images` を保持してください。ゲーム内蔵のMODローダーを使用するため、BepInExは不要です。

## 使い方

1. 初期設定の **バッククォート（数字1の左側のキー）**、または変更した絵文字キーを押し続けます。
2. マウスを使いたい絵文字の枠内に移動し、キーを離します。
3. 空白部分でキーを離すか **Esc** を押すとキャンセルします。

5つの枠は正五角形に配置され、選択中の枠は明るい縁で強調されます。種類数が異なる場合も自動配置します。ゲーム本来のマウスホイールクリックによるピンも利用できます。

- キー変更：**設定 → キーボード → 絵文字選択（EP）**
- 画像再読み込み：同じタブの **絵文字画像（EP）→ 再読み込み**、または **Ctrl + 現在の絵文字キー**。設定項目名は韓国語で表示される場合があります。
- 初期表示時間は2.5秒、使用間隔は0.75秒です。

## カスタム絵文字

`Images` の下に絵文字ごとのフォルダーを作り、`1.png`、`2.png`、… `8.png` の名前でフレームを保存します。1枚なら静止画になります。番号は連続させ、すべてのフレームを同じサイズにしてください。

| 項目 | 仕様 |
|---|---|
| 推奨サイズ | 16×16または24×24。表示サイズと揃える |
| 元画像の最大サイズ | 1フレーム64×64 |
| 表示サイズ | 長辺8～24論理ピクセル |
| 形式 | 8ビットRGBA PNG。背景透過を推奨 |
| アニメーション | 最大8フレーム、1～12 FPS |
| 容量・種類数 | 1種類につき最大1 MiB、1パック最大8種類 |

ピクセル用の鉛筆ツールで制作し、アンチエイリアスやぼかしを避けてください。新しいフォルダーは **`pack.json` の `emojis` 配列にも登録が必要**です。自動検出には対応していません。例えば `Images/my-heart` に24×24の画像を置く場合、次の項目を追加します。

```json
{"id":"my-heart","name":"ハート","folder":"my-heart","fps":8,"displayPixels":24}
```

保存後、画像を再読み込みすると反映されます。ZIPの `Templates` には透明フレームと、親指を立てる8フレームの制作例が含まれます。

## マルチプレイ

Steamロビーでは同じ最新バージョンのMODを使うプレイヤー同士が、それぞれのカスタム絵文字を直接共有します。MOD使用者にはマルチプレイ一覧の名前の右側に **EPマーク** が表示されます。未導入のプレイヤーにはマークとMODの絵文字は表示されません。ホストの導入状況に依存しない共有を実装しており、直接通信できない場合も自分の画面での表示は利用できます。

## 自動更新

ゲームがMODを読み込む際に、このリポジトリの最新の正式Releaseを確認します。新バージョンがあればゲーム内に確認画面を表示し、同意するとダウンロード後、ゲームを終了して更新・再起動します。**先に進行状況を保存してください。** カスタム画像、パック設定、個人のキー設定は保持します。

`EmojiPing-update.zip` は既存環境の自動更新専用です。初回は全体のZIPを使用してください。確認を無効にするにはMODフォルダーに空の `disable-updates.txt` を作成します。失敗時はゲームフォルダーの `__EmojiPing_Update.log` と `Player.log` を確認してください。
